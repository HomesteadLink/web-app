# Wireframe renders — HomeSteadyLink mobile PRD

PNG renders of the 16 wireframe SVGs in `HomesteadLink/mobile-app`
`docs/wireframes/` (the SVG source of truth; PNGs are never committed
there). Rendered with headless Chromium at 860x1800 from main `049e3a93`
(PR #67, post-simplicity screens, Nov 17, 2026).

These files are the images embedded in the Notion PRD
("PRD — Screens & Wireframes") as external URLs:
`https://homesteadlink.github.io/web-app/wireframes/<name>.png`

To refresh after a wireframe redraw: re-render the SVGs from the
mobile-app repo at HEAD and replace these PNGs in place (same filenames),
so the PRD embeds stay current without a Notion edit.
