⌁ HomeSteadyLinkFirmware v1.3

Install the firmware

Put HomeSteadyLink firmware v1.3 on your router’s SD card, then start it for the first time. The board is an Orange Pi Zero 2W.

Swapping the SD card is the only way to install or update the firmware. There is no update over the internet and no update from the setup page. To change the firmware, write a new card and swap it in.

1. Download the firmware

Download the v1.3 image from the release page:

HomeSteadyLink firmware v1.3 — release page

On that page, download this file:

homesteadlink-v1.3-orangepizero2w.img.xz (about 559 MB)

Do not download any other version from anywhere else. v1.4.0 is not released yet and is not available to download.

2. Check the download is genuine

Before you write the card, check the file’s checksum. The checksum is a fingerprint of the file — if it matches, the download is complete and untampered.

The correct SHA-256 checksum for homesteadlink-v1.3-orangepizero2w.img.xz is:

ea0d155c2250c955dae0aab4c7ce57e080051891b51079047c07cf2fcc01f114

Run one of these in a terminal, in the folder where you downloaded the file:

macOS:

shasum -a 256 homesteadlink-v1.3-orangepizero2w.img.xz

Linux:

sha256sum homesteadlink-v1.3-orangepizero2w.img.xz

Windows (PowerShell):

Get-FileHash homesteadlink-v1.3-orangepizero2w.img.xz -Algorithm SHA256

Compare the output with the checksum above, character by character. If it does not match exactly, delete the file and download it again — do not flash it.

3. Write the image to the SD card

You need a microSD card and a card reader (built into your computer or a USB adapter). Pick one of the two ways below.

Option A — Balena Etcher (easiest, all systems)

  1. Download and install Etcher from etcher.balena.io.
  2. Put the microSD card in the reader and open Etcher.
  3. Click Flash from file and pick homesteadlink-v1.3-orangepizero2w.img.xz. Etcher can flash the compressed file directly — you do not need to unpack it first.
  4. Click Select target and pick the SD card. Double-check it is the card and not your computer’s hard drive.
  5. Click Flash! and wait until Etcher says it is done, then remove the card safely.

Option B — dd (macOS / Linux)

  1. Unpack the download first: xz -dk homesteadlink-v1.3-orangepizero2w.img.xz — this leaves a .img file next to it.
  2. Find the card’s device name. On macOS run diskutil list; on Linux run lsblk. Note the device for the SD card (macOS: something like /dev/disk2; Linux: something like /dev/sdX or /dev/mmcblk0).
  3. Unmount the card. On macOS: diskutil unmountDisk /dev/diskN (replace N with your card’s number). On Linux: sudo umount /dev/sdX* (replace sdX with your card’s device).
  4. Write the image: sudo dd if=homesteadlink-v1.3-orangepizero2w.img of=/dev/diskN bs=4M status=progress conv=fsync — replace /dev/diskN with your card’s device from step 2.
  5. Wait until dd finishes, then eject the card safely: macOS diskutil eject /dev/diskN, Linux sudo eject /dev/sdX.
Be careful with dd: writing to the wrong device erases that drive completely. Check the device name twice before you press Enter.

4. First boot — save the identity line

Put the SD card in the router and power it on.

At the very first boot, the router prints a line starting with HSL-IDENTITY on the serial console. That line holds your router’s serial number, its setup code, its console password, and its Wi-Fi passphrase (ap_passphrase). It is printed on the serial console only at first boot — or again after a factory reset (HSL-RESET).

Copy the whole line and keep it somewhere safe. You will need the setup code and the console password later, and they are not shown anywhere else.

5. Set the router up

Once the router has booted, set up Wi-Fi and the VPN on the setup page:

Open the setup page

Plug the router into this computer with a USB cable and follow the steps there. No setup code is needed on that page — the USB connection itself is the proof the router is yours.
